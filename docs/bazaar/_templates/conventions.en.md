a list of conventions and things to check at the end of writing each doc:
1. make sure the doc is following the item template _item_template.en.md
2. the title of the doc should be short and straight forward, only naming the item the doc is discussing, and nothing more.
3. the introduction should be short, straight forward and to the point. remove any unnecessary adjectives and descriptions.
4. all the sources are formated correctly, grouped under the right source category and contain a url link and a short note about it.
