# Key Terms & Concepts — Logic

A curated, scannable reference of important terms in logic. Hover a term to reveal its
definition, aliases, and an external anchor. Terms are grouped by real sub-topics — never a
`General` or `Other` catch-all.

## Propositional Logic

<div class="annotate" markdown>

- Proposition (1)
- Logical connective (2)
- Truth table (3)
- Tautology (4)
- Material conditional (5)
- Boolean algebra (6)

</div>

1.  A declarative statement that is either true or false, the basic unit that logic reasons about. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Proposition).
2.  A symbol or word (such as and, or, not, if…then) that joins propositions into more complex ones. **Aliases:** logical operator. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Logical_connective).
3.  A table listing every combination of truth values of a formula's components and the resulting truth value of the whole. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Truth_table).
4.  A formula that is true under every possible assignment of truth values to its variables. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Tautology_(logic)).
5.  The truth-functional connective "if…then", false only when the antecedent is true and the consequent false. **Aliases:** material implication. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Material_conditional).
6.  The algebra of the truth values true and false under the operations conjunction, disjunction, and negation. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Boolean_algebra).

## Predicate Logic

<div class="annotate" markdown>

- First-order logic (1)
- Predicate (2)
- Quantifier (3)
- Higher-order logic (4)

</div>

1.  A formal system that extends propositional logic with predicates, variables, and quantifiers over objects. **Aliases:** first-order predicate calculus, FOL. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/First-order_logic).
2.  A symbol expressing a property of, or relation between, objects, which becomes true or false once its arguments are supplied. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Predicate_(mathematical_logic)).
3.  An operator specifying how many objects in a domain satisfy a formula — chiefly the universal ("for all") and existential ("there exists") quantifiers. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Quantifier_(logic)).
4.  Logic that permits quantification over predicates and relations, not only over individual objects. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Higher-order_logic).

## Proof & Inference

<div class="annotate" markdown>

- Inference (1)
- Deductive reasoning (2)
- Syllogism (3)
- Modus ponens (4)
- Modus tollens (5)
- Natural deduction (6)
- Soundness (7)
- Completeness (8)

</div>

1.  The process of deriving a conclusion from premises according to logical rules. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Inference).
2.  Reasoning in which the conclusion follows necessarily from the premises, so true premises guarantee a true conclusion. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Deductive_reasoning).
3.  A form of deductive argument in which a conclusion is drawn from two premises, central to Aristotle's logic. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Syllogism).
4.  The rule of inference "if P then Q; P; therefore Q". **Aliases:** affirming the antecedent. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Modus_ponens).
5.  The rule of inference "if P then Q; not Q; therefore not P". **Aliases:** denying the consequent. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Modus_tollens).
6.  A proof system that models reasoning through introduction and elimination rules for each connective, rather than through axioms. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Natural_deduction).
7.  The property of a proof system whereby every provable statement is actually true (valid). **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Soundness).
8.  The property of a proof system whereby every true (valid) statement is provable within it. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Completeness_(logic)).

## Modal Logic

<div class="annotate" markdown>

- Modal logic (1)
- Possible world (2)
- Kripke semantics (3)

</div>

1.  The logic of modalities such as necessity and possibility, extending classical logic with operators like "necessarily" and "possibly". **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Modal_logic).
2.  A complete and consistent way the world could have been, used to give meaning to claims of necessity and possibility. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Possible_world).
3.  A formal semantics for modal logic in which necessity and possibility are interpreted over a set of possible worlds linked by an accessibility relation. **Aliases:** relational semantics, possible-world semantics. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Kripke_semantics).

## Set Theory & Foundations

<div class="annotate" markdown>

- Axiom (1)
- Set theory (2)
- Zermelo–Fraenkel set theory (3)
- Russell's paradox (4)

</div>

1.  A statement accepted without proof as a starting point for deriving other results. **Aliases:** postulate. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Axiom).
2.  The branch of mathematical logic that studies sets — collections of objects treated as a single entity — as a foundation for mathematics. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Set_theory).
3.  The standard axiomatic foundation of set theory, usually taken together with the axiom of choice (ZFC). **Aliases:** ZF, ZFC. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Zermelo%E2%80%93Fraenkel_set_theory).
4.  The contradiction, discovered by Bertrand Russell, arising from the set of all sets that do not contain themselves; it showed naive set theory to be inconsistent. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Russell%27s_paradox).

## Computability & Metalogic

<div class="annotate" markdown>

- Gödel's incompleteness theorems (1)
- Turing machine (2)
- Decidability (3)
- Halting problem (4)

</div>

1.  Two theorems showing that any consistent formal system rich enough for arithmetic contains true statements it cannot prove, and cannot prove its own consistency. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/G%C3%B6del%27s_incompleteness_theorems).
2.  An abstract machine that manipulates symbols on a tape according to rules — the standard model of what it means to be computable. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Turing_machine).
3.  The question of whether an effective procedure exists that always correctly decides whether a statement belongs to a given set. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Decidability_(logic)).
4.  The proof that no general algorithm can decide, for every program and input, whether the program eventually halts. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Halting_problem).

## Fallacies

<div class="annotate" markdown>

- Formal fallacy (1)
- Affirming the consequent (2)
- Circular reasoning (3)
- Straw man (4)

</div>

1.  An argument whose reasoning is invalid because of a flaw in its logical structure, regardless of the truth of its premises. **Aliases:** logical fallacy, non sequitur. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Formal_fallacy).
2.  The invalid inference "if P then Q; Q; therefore P". **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Affirming_the_consequent).
3.  A fallacy in which the conclusion is assumed among the premises, so the argument establishes nothing new. **Aliases:** begging the question, petitio principii. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Circular_reasoning).
4.  Misrepresenting an opponent's position to make it easier to attack. **See also:** [Wikipedia](https://en.wikipedia.org/wiki/Straw_man).
