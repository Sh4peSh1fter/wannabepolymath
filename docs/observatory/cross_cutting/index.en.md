# Cross-Cutting Concepts

Some ideas refuse to stay in one field. **Entropy** lives in physics *and* information theory;
a **graph** is a mathematical object, a data structure, and a social model; **equilibrium**
recurs from economics to chemistry. Folders can only file a term in one place — this map is
where those terms are connected across the whole Observatory.

## How it works

- **Define once, link many.** Each concept is defined in full in its most-native field. Other
  fields and this map only add a one-line, field-specific gloss and a link into that treatment.
- **`concept:` tags** are the machinery: the canonical entry and every field that references
  the term share a `concept:<term>` tag, so [Browse by Tag](../tags.en.md) becomes an automatic
  "every field touching this concept" pivot.
- **Dedicated pages** (below) are reserved for concepts that genuinely span **3+ fields**.
