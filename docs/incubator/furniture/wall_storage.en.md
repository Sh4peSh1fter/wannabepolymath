# Wall Storage



## Requirements Analysis

1.  Primary Function: Tool storage (likely moderate to heavy weight).
2.  Wall Area: Max 1.5m (W) × 2m (H)
3.  Wall Type: Concrete (drillable, but not ideal if you prefer not to).
4.  Budget & Aesthetics: Cost-efficient, industrial/functional look.
5.  Modular Requirement: Able to reconfigure, add accessories, evolve.
6.  Bonus Tool: 3D printer for custom accessories.

## Core system

1. pegboard wall
2. french cleat  
3. honeycomb (HSW)
4. Multiboard
