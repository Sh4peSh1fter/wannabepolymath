# קורסים

קורסים הם **מסלולי למידה מובנים**: רצף של שיעורים עם מפת דרכים חזותית, תוכנית לימודים, ומטרות
מדידות בכל שלב. בעוד ש[מדריך](../tutorials/index.en.md) מלמד דבר אחד בישיבה אחת, קורס לוקח אותך
מהיסודות ועד שליטה לאורך כמה שיעורים — כשכל אחד הוא יחידה עצמאית שמסתיימת בעבודת כיתה ובמילון
מונחים משלה.

מסלול בן חמישה קורסים — משורת הקוד הראשונה ועד התמחות. מתחילים ביסודות, ממשיכים לעומק, ואז
מסתעפים לתחום שמעניין אתכם.
