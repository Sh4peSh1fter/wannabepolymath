# Courses

Courses are **structured learning paths**: a sequence of lessons with a visual roadmap, a syllabus,
and measurable objectives at every step. Where a [tutorial](../tutorials/index.en.md) teaches one
thing in one sitting, a course takes you from foundations to competence over several lessons — each
a self-contained node that ends with classwork and its own key-terms glossary.

## The Python track

A five-course path from your first line of code to a specialization. Start with the fundamentals,
then go deep, then branch into the domain that interests you.

<div class="grid cards" markdown>

-   [**Python for Beginners**](./python_for_beginners/index.en.md)

    ---

    Start here. The Python fundamentals from zero — syntax, data structures, functions, files, and
    developer tooling.

-   [**Python Advanced**](./python_advanced/index.en.md)

    ---

    From scripts to software: OOP, functional Python, data structures & algorithms, concurrency,
    typing, testing, and packaging.

-   [**Python Web & APIs**](./python_web_and_apis/index.en.md)

    ---

    Build for the web — HTTP fundamentals, Flask, FastAPI, Django, visualization, and deployment.

-   [**Python & Networks**](./python_and_networks/index.en.md)

    ---

    Network programming — TCP/IP fundamentals, sockets, and packet crafting with Scapy.

-   [**Python & Data**](./python_and_data/index.en.md)

    ---

    Work with data — Jupyter, NumPy, pandas, visualization, and SQL/NoSQL databases.

</div>
