# Tutorials

Tutorials are **learning-oriented, hands-on lessons**: a beginner follows along and builds one
concrete thing from start to finish. They prioritise confidence and a working result over
completeness. Reach for a [course](../courses/index.md) when the subject needs several sequenced
lessons; reach for a [how-to guide](../how_to_guides/index.en.md) when the reader already knows the
basics and just needs the steps.
